# Features

- **Single line** — dir · git branch · model · `ctx%` · 5h/7d usage bars.
- **Color‑coded** with a live reset countdown (`↻`).
- **Works on any plan** — uses the built‑in `rate_limits` JSON for Pro/Max subscribers, otherwise probes the endpoint's rate‑limit headers.
- **Non‑blocking** — the probe runs in the background and is cached, so rendering stays instant (~60ms).
- **6 styles**, and **no secrets stored** — your account is read from the environment at runtime.
